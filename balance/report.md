# ランダム20人戦：能力バランス検証（2026-10-05）

計2,000試合を実行。変更前800試合、最終変更後800試合、採用しなかった強化量の調整400試合。

## 条件

- 本体の共通基礎値：攻撃力16、HP1200、速度5.5。名前由来の基礎値差と保存済み編集値を除去。巨大化・支援能力のHP補正など、能力固有の補正は維持。
- 65能力から重複なしで20能力をランダム抽出。能力の配置順、初期位置、移動方向、各種判定も乱数で決定。
- HTML内の実際の戦闘処理をNode.jsで実行。描画と表示用タイマーのみ省略し、ダメージ・移動・能力・ゲーム内タイマー・サドンデス・勝敗判定は使用。
- 同じ参加能力・開始シードの400試合を変更前後で比較。戦闘中の乱数消費は能力発動によって変わるため、変更前後の全乱数列が同一であるという意味ではない。
- 調整用シード20261005とは別の20261105で、変更前後各400試合も実行。シードは各試合で7919ずつ加算。
- 1試合90秒まで。勝者なし、または時間切れは勝利として数えない。上位5率は「チームが生存している時点で残りチームが5以下になった率」。死亡時分裂の破片もチーム生存に含む。
- 実ゲームの名前由来のランダム基礎値は維持。固定値はこの検証だけに使用。

## 弱い能力の選定

最初の400試合で勝利0回、上位5率3%未満の5能力を選定。出場数は121〜142回。上位5率を等強仮説の25%と比べる片側二項検定を行い、65能力の比較をHolm法で補正した。この仮説は能力間の等強を仮定する比較の目安であり、あらゆる対戦条件の強弱を証明するものではない。

## 最終結果：変更前後それぞれ800試合

勝率の分母はその能力の出場回数。異なる能力を組み合わせて戦うため、各能力の出場数は完全には等しくない。

| だんだん攻撃力UP | 244 | 0→24 | 0.0%→9.8% | 3.7%→29.9% | 25.2→28.6 |

| 能力 | 出場数 | 勝利数 前→後 | 上位5率 前→後 |
|---|---:|---:|---:|
| ジェット突進 | 117 | 0→0 | 0.0%→10.3% |
| だんだん攻撃力UP | 119 | 0→12 | 5.9%→31.9% |
| 酸噴射 | 120 | 0→8 | 1.7%→29.2% |
| 分身 | 114 | 0→1 | 5.3%→8.8% |
| 水流押し流し | 108 | 0→0 | 1.9%→16.7% |

別シードでも5能力すべての上位5率が上昇した。ただし分身の改善量は小さく、単独の400試合から確かな改善幅を断定するには不足。ジェット突進と水流押し流しの勝利数もまだ少ない。今回の変更は弱い能力の使いどころと生存力を改善したもので、全65能力の均等化を完了したものではない。

## 採用した強化

- ジェット突進：3.5秒ごとに0.9秒突進、接触攻撃4倍、突進中の被ダメージ30%軽減、HPを削った命中で最大HP1%回復。
- だんだん攻撃力UP：毎秒の攻撃力増加を1.8→7.2に。経過時間に応じて最大30%の被ダメージ軽減。
- 酸噴射：敵に向けて噴射し、範囲260・角度120度・2.5秒間隔。初撃は攻撃力5倍。4秒間、0.5秒ごとに攻撃力75%の腐食ダメージ。腐食は重複せず再付与で更新。
- 分身：6秒間隔、最大3体。HP35%・攻撃力75%。生存する分身1体につき本体の被ダメージ15%軽減、最大45%。
- 水流押し流し：3.5秒間隔、範囲190、攻撃力2.5倍。0.5秒の吹き飛ばしと1秒の20%遅化。HPを削った敵1体につき最大HP1%回復、1回の発動では4%まで。

最初の強化案ではジェット突進47.9%、水流押し流し33.1%の勝率になったため不採用。回復量・防御効果・発動頻度を下げてから上記の最終結果を測定した。

```bash
node scripts/simulate-balance.cjs /tmp/battle-before.html /tmp/before.json 400 20261005
node scripts/simulate-balance.cjs index.html /tmp/after.json 400 20261005
node scripts/simulate-balance.cjs /tmp/battle-before.html /tmp/holdout-before.json 400 20261105
node scripts/simulate-balance.cjs index.html /tmp/holdout-after.json 400 20261105
```

JSONには全65能力の出場数・勝利数・勝率のWilson 95%区間・上位5率・生存時間を収録。全能力の比較表は `comparison.csv`。描画は省略しているため、実ブラウザの見た目や処理負荷はこの検証の対象外。
