# エフェクト残留の修正（2026-10-05）

一時エフェクトとダメージ表示の削除は実時間の `setTimeout` を使用していた。倍速ではゲーム側の生成頻度だけが上がり、多人数戦やメインスレッドが忙しい状態で表示とタイマーが溜まる。また終了処理は戦闘の更新を止めるため、更新処理で削除される竜巻・弾・ゾーン・ワープが終了画面に残った。

一時表示をゲーム内時刻の期限付きMapで管理し、各ステップで削除する方式へ変更。時間停止による戦闘タイマーの停止とは独立させた。一時表示は400件を上限とし、超過時は古い表示のみ削除する。ワープなど戦闘オブジェクトの寿命と当たり判定は維持する。終了・中止・再準備では一時表示と戦闘オブジェクトのDOMを一括削除し、生存キャラクターと勝者表示は残す。

## 検証

```bash
npm install --no-save jsdom
node scripts/test-effect-lifecycle.cjs
```

jsdomで実際のHTMLと戦闘・再生ループを実行し、実時間タイマーを無効化した状態で検証。

- 60人、0.5・1・2・4倍速で期限切れ表示が削除される。
- 60個/ステップの生成を120ステップ繰り返し、短命エフェクトの保有数は60件で推移。
- 一度に2,000個生成しても400件まで。
- 時間停止中にも一時表示の期限切れが削除される。一時停止ではゲーム時間を保ち、再開後に削除される。
- ワープの2つの表示は寿命中維持され、終了時に竜巻・爆弾・壁・一時表示とともに削除される。
- 勝者DOMは維持され、中止・再準備で前試合の一時表示が残らない。
- 既存の入力・保存・編集・一時停止・再生速度の回帰確認、および6・20・60人の試合完走を確認。

同一シードの20人戦30試合で変更前後の勝敗・全65能力の集計が完全一致し、戦闘結果への影響がないことを確認。

実ブラウザでの描画・負荷の目視検証は行っていない。
